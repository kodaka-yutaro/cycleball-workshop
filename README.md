# Cycleball Workshop

サイクルサッカーの自転車を、一人称視点で分解・組み立てする学習用ワークショップ。

## 操作

- WASD / 矢印: 自転車の周りを移動
- マウスまたはドラッグ: 視点操作
- C: しゃがむ / 立つ
- 1〜5: 手・スパナ・六角レンチ・ペダルレンチ・ラジオペンチ
- E: 照準の部品に工具を合わせる（適合工具・距離・作業順を確認）
- 回転ダイヤルをなぞる / 方向別ボタン長押し / 左ボタン・Space長押し: 工具を回す・部品を引き抜く。離すと停止
- R: 時計回り / 反時計回り
- G: 外した部品を持つ / 床に置く（フリーモード、手）
- Esc: 作業中断・ポインターロック解除

パーツ一覧から対象の近くへ移動できます。観察モードはOrbitControlsで回転・拡大できます。スマートフォンでは左下のスティックで移動し、3D画面を別の指でスワイプして見回します。作業中の照準は上部へ移動し、下部の工具ダイヤル・方向別ボタン・長押しボタンで操作します。解説は折りたたみ可能です。

## 形状

STAR BICYCLE公式Radballページの車体画像を参考に、水平に後方へ伸びるサドル支持部、トップチューブ・シートステーの位置、車輪間隔、小径チェーンリング、前上方へ曲がる細身のハンドル、ストレートフォークを近似した手続き型3Dモデルです。

- 参考: https://www.starbicycle.com/bike-customizer/radball
- 参照画像: https://cdn.prod.website-files.com/5bcae6d91740e33ea6b9c593/5c65d171782e386af6e0168c_sb-radball-mockup.png
- 写真ファイル・メーカーのロゴは配布物に含めていません。
- 非公式モデルです。メーカー提供CAD・実測寸法ではありません。
- 18の操作対象。車軸ナットと張り調整ねじは左右別々です。フレーム・フォーク・クランク・ベアリング内部の分解は未対応。
- チェーンのローラー・プレート・クリップ式接続部を再現。後輪を前へ動かして張りを抜き、クリップ、プレート・ピン、チェーンを順に取り外します。後輪・チェーン整備ガイドは22手順です。
- 接続クリップと張り調整ねじは一般構造の学習モデルで、STAR実車の仕様を断定しません。
- 回転数・移動量は模擬値です。工具寸法は練習用の初期値を使い、部品ごとに変更できます。トルク、張り量、摩耗診断は厳密には再現しません。
- 回転は工具を当てる側から見た方向です。左ペダルは逆ねじ、左の車軸ナットは通常ねじ。間違った方向では進捗しません。
- 参照: https://www.parktool.com/en-us/blog/repair-help/chain-replacement-single-speed-bikes

## ローカル実行

外部パッケージのインストール・ビルドは不要です。Python 3があれば:

```bash
python -m http.server 8080 --directory dist
```

ブラウザーで http://localhost:8080 を開きます。ES Modulesのためfile://では動きません。

```bash
npm test
npm run check
```

Node.js 20以上。Three.js 0.180.0と必要な拡張をdistに同梱し、3DのCDN依存を避けています。Google Fontsは任意で、読み込めない場合はシステムフォントに戻ります。ライセンスはdist/THREE-LICENSE.txt。

## 実装

- dist/engine.js: モデル、部品の当たり判定、FPS移動、工具と手の3Dモーション、部品運搬
- dist/app.js: フリー/ガイド、長押し・中断・逆回転、保存、UI
- dist/mechanics.js: 分解・組立の依存関係、ねじ方向、保存位置の検証
- dist/data.js: 部品と5種類のレッスン
- dist/index.html / dist/style.css: 画面とレスポンシブUI

作業状態はブラウザー内に保存されます。WebGLが使えない環境ではSVGRendererによる軽量3Dに切り替わります。

## 工具・部品マップの更新 (2026-10-23)

- 工具ベルトの「部品・工具マップ」から18か所の番号付き模式図を開けます。部品名の選択欄もあり、選択した部品の近くへ移動できます。
- 部品ごとに工具、寸法、緩める向き、事前の分解条件、現在の操作可否を表示します。
- スパナ・六角レンチ・ペダルレンチは寸法を選択します。種類だけでなくサイズが合わない場合も操作を拒否します。3D工具の口径・太さも選択に応じて変化します（形状は模擬）。
- **初期値はSTAR実車の確認済み寸法ではありません。** 車軸ナット15 mm、張り調整ねじ10 mm、クランプ六角6 mm、ペダルレンチ15 mmは学習用の仮設定です。ユーザー設定と公式の掲載情報を分けて表示します。
- 部品マップから個々の必要サイズを設定し、既存の `cw-state-v3` に保存します。旧保存データは維持して不足項目を補います。設定を初期値に戻すこともできます。
- 番号付き対応表をテキスト欄で選択・コピーできます。「01は17 mm」のように、実車確認後の修正指示に利用できます。
- ガイドの点検工程は3項目のチェックを終えてから次へ進みます。実車の自動診断ではありません。
- スマートフォン向けに工具サイズ選択欄、44 pxのマップボタン、横スクロールする図と部品名選択欄を用意しました。
